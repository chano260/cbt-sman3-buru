# Uji Beban Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Skrip `scripts/uji-beban.js` yang mensimulasikan siswa & pengawas serentak pada server tes terpisah dan menyimpulkan sanggup/tidak.
**Architecture:** Proses induk = penyiap data + pembangkit beban + pencatat statistik; proses anak = `server.js` dengan DB sementara.
**Tech Stack:** Node 22 (fetch bawaan, child_process), node:test.
**Spec:** `docs/superpowers/specs/2026-11-22-uji-beban-design.md`

## Global Constraints
- Port bawaan 8199; tujuan selalu `127.0.0.1`. Bawaan 500 siswa / 15 pengawas / 5 menit / datang bertahap 60 dtk.
- Ambang: SANGGUP p95 < 1000 ms & gagal < 1%; BERAT p95 ≤ 3000 ms; selain itu TIDAK SANGGUP.

## Review Focus
- Port 8199 sudah dipakai → berhenti dengan pesan jelas, bukan menguji server lain.
- Server tes gagal menyala → pesan jelas + log server, folder sementara tetap dibersihkan.
- Ctrl+C di tengah uji → server tes dimatikan & folder sementara dihapus.
- Token berganti di tengah uji → siswa yang ditolak 403 mengambil token baru dan mencoba lagi.
- Siswa yang gagal login tetap dihitung sebagai "gagal", tidak membuat skrip berhenti.
